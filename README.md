# Aasra - Pension Application

Aasra is a dedicated Android application designed to simplify and streamline the pension process for citizens. It provides a secure and user-friendly platform for managing documents, tracking applications, and accessing support services.

## 🚀 Features

- **Document Vault**: Securely store and manage all your essential documents in one place for easy access during the pension process.
- **Track Application**: Real-time tracking of your pension application status.
- **Track Ticket**: Keep an eye on your support or complaint tickets.
- **Voice Assistant**: Integrated voice assistance to improve accessibility for elderly users.
- **Pension Management**: Specific modules to handle pension-related tasks and information.
- **Chatbot Support**: Get instant help through the built-in chatbot.
- **Secure Authentication**: Robust Login and Signup system to protect user data.
- **User Settings**: Personalized app experience with theme and profile management.

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI Framework**: XML (Material Design)
- **Architecture**: Modern Android Development practices
- **Components**: 
    - ViewBinding
    - ConstraintLayout
    - RecyclerView
    - Material Components for Android
